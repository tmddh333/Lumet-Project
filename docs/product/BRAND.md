# Lumet — 브랜드 가칭 검토 (2026-10-03 KST)

- **가칭:** Lumet(루멧). Lumi(빛을 연상)와 Comet(혜성)의 결합에서 영감을 얻은 이름. 등록 상표나 독점 사용권이 확인된 이름이 아니다.
- **브랜드 의미:** AI가 만든 코드를 이해하고 스스로 판단할 수 있도록 빛을 비추는 친구.
- **문구:** `Illuminate the code.`
- **기능 명칭:** Lumet Trace / Lumet Review / Lumet Paths.
- **시각 언어:** 짙은 남색·검정에 블루/인디고 포인트, 반짝이는 혜성 로고. 학습 화면에서는 장식 최소화, 높은 텍스트 대비, 라이트·다크 모드 동등 지원.

## 출시 전 해야 할 일

1. KIPRIS(https://www.kipris.or.kr/)에서 `Lumet`, `LUMET`, `루멧`, 유사 발음 및 표장 검색. 소프트웨어(9), 교육(41), SaaS(42)에 연관된 실제 지정상품을 전문가와 확인.
2. 사용 국가의 상표 DB와 앱스토어에서 문자·도형·발음 유사도를 추가 검색.
3. 도메인 등록사업자에서 후보 도메인의 **구매 가능 여부와 갱신 가격**을 실시간 확인. 현재 웹사이트가 안 뜬다고 등록 가능하다는 뜻은 아님.
4. GitHub/소셜 계정 식별자 확인, 출시 전 변리사 자문 고려.
5. 브랜드 충돌 발견 시 가칭은 유지하되 출시명 변경을 가능하게 하는 UI 문자열/에셋 분리.

이 문서는 1차 공개 웹 조사이며 상표 사용 허락, 법률 의견, 등록 가능성 보장이 아니다.
