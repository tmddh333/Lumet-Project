# Lumet — UI/UX 가이드 v0.2

## 방향

- **가독성 우선**: 우주 그래픽은 작은 로고와 브랜드 소개에만 쓰고, 학습 화면에서 불필요한 배경 광원·그라데이션·지표 카드를 줄인다.
- **테마**: 기본은 사용자 OS의 `prefers-color-scheme` 설정을 따르며 헤더의 테마 버튼으로 라이트/다크 전환. 명시적 사용자 선택은 `localStorage`에 저장한다.
- **색 의미**: 인디고는 주요 행동·현재 단계, 민트는 실행 상태/성공 피드백, 빨강·주황은 실제 오류/주의에만 사용.
- **폰트**: OS 기본 한글 UI 글꼴과 시스템 고정폭 코드 글꼴. 외부 유료 폰트 없음.

## 4개 화면

1. **Home**: 한 문장 가치 제안, 기술 선택 CTA, 오늘의 실습. 불필요한 수치 배지 제거.
2. **Stacks**: 검색, 제공 중인 언어별 샘플, 미지원 기술 관심 등록; 지원 여부 숨김 금지.
3. **Trace**: 코드·현재 줄 강조·단계 제어·상태 변화·해설. '검증된 시나리오, 실제 실행 아님' 라벨 필수.
4. **Review**: 결과 예측과 문제 식별 → 제출 → 이유 및 다음 학습.

## 접근성 및 회귀 기준

- 360px·390px 화면에서 페이지 전체의 불필요한 수평 스크롤이 없어야 한다. 코드 영역은 독립적인 가로 스크롤 허용.
- 라이트/다크 전환 시 탐색 화면·문제 선택·재생 위치를 초기화하지 않는다.
- 테마 전환 버튼의 텍스트 대체와 키보드 포커스를 제공하고 44×44px 터치 영역을 확보한다.
- 사용자 선택 테마는 새로고침 후 유지하며 초기 상태는 시스템 테마를 따른다.
- 조작 상태를 색상 하나에만 의존해 표현하지 않는다.
- `prefers-reduced-motion`에서 비필수 전환 효과 제거.
